# 8. Основные атрибуты качества

В качестве основных выбираются три атрибута.

## QA-01. Масштабируемость

### Причина

- Пользователи находятся по всему миру.
- Возможны массовые спортивные соревнования.
- Нагрузка может сильно изменяться во времени.

### Особенно важна для

- Training.
- Analytics.
- Competitions.
- Notifications.

## QA-02. Надёжность

Тренировочные данные не должны теряться даже при нестабильной сети или временной недоступности отдельных компонентов.

### Особенно важна для

- Мобильного клиента.
- Training.
- Интеграций с устройствами.

## QA-03. Безопасность и конфиденциальность

Система работает с персональными, геолокационными и потенциально чувствительными спортивными данными.

### Особенно важна для

- Identity.
- Training.
- Social.
- Devices.
- Analytics.
