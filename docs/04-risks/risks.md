# 5. Первоначальный анализ рисков

## RISK-01. Быстрый рост нагрузки во время крупных соревнований

**Тип:** Технический.

Большое количество пользователей может одновременно отправлять тренировочные данные и запрашивать рейтинги.

### Последствия

- Рост задержек.
- Недоступность отдельных функций.
- Потеря данных.

### Направление решения

- Горизонтальное масштабирование.
- Асинхронная обработка.
- Очереди событий.
- Нагрузочное тестирование.

## RISK-02. Потеря тренировочных данных при нестабильной сети

**Тип:** Технический.

Пользователь может тренироваться в месте с отсутствующим или нестабильным интернетом.

### Направление решения

- Локальное сохранение данных.
- Последующая синхронизация.
- Идемпотентная обработка повторной отправки.

## RISK-03. Утечка персональных и геолокационных данных

**Тип:** Бизнес / технический / юридический.

Приложение может обрабатывать:

- Геолокацию.
- Маршруты пользователя.
- Информацию о тренировках.
- Физиологические показатели.

### Направление решения

- Privacy by Design.
- Минимизация собираемых данных.
- Шифрование.
- Управление доступом.
- Управление согласием пользователя.

## RISK-04. Сложность интеграции большого числа внешних устройств

**Тип:** Технический.

Различные производители используют разные протоколы и форматы данных.

### Направление решения

Создание отдельного integration layer и унифицированной внутренней модели спортивных данных.

## RISK-05. Избыточная сложность системы на раннем этапе

**Тип:** Архитектурный / бизнес.

Попытка реализовать одновременно все требования может значительно увеличить стоимость и сроки проекта.

### Направление решения

Поэтапная разработка системы и выделение MVP.

## RISK-06. Недостаточный интерес пользователей к социальным функциям

**Тип:** Бизнес.

Пользователи могут предпочитать существующие социальные платформы.

### Направление решения

Ранняя проверка социальных механик и постепенное расширение функций.

## RISK-07. Нерелевантные рекламные предложения

**Тип:** Бизнес.

Большое количество рекламного контента может снижать вовлечённость.

### Направление решения

Делать промо вторичным относительно спортивного опыта пользователя.
