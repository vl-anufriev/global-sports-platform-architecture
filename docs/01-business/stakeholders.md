# 3. Стейкхолдеры

| Стейкхолдер | Основные интересы |
| --- | --- |
| Пользователи | Тренировки, статистика, мотивация, удобство |
| Спортсмены | Точность тренировочных данных и сравнения |
| Социальные группы | Совместные тренировки и коммуникация |
| Менеджмент компании | Вовлечённость и влияние приложения на бизнес |
| Маркетинг | Персонализированные предложения и акции |
| Product Management | Развитие продукта и контроль приоритетов |
| Команды существующих приложений | Простая и стабильная интеграция |
| Разработчики | Понятные границы компонентов и удобство развития |
| DevOps / SRE | Эксплуатация, масштабирование, наблюдаемость |
| Information Security | Защита пользовательских данных |
| Legal / Compliance | Выполнение региональных требований |
| Support | Диагностика пользовательских проблем |
| Поставщики устройств | Стабильные интерфейсы интеграции |
