# ADR-012. Использование CDN для публичного контента

**Статус:** Proposed

## Context

Приложение предназначено для глобальной аудитории и может содержать:

- изображения;
- спортивные новости;
- рекламные материалы;
- другие статические ресурсы.

Передача таких данных непосредственно из основного backend увеличивает нагрузку
и задержку для удалённых пользователей.

## Decision

Предусмотреть возможность использования CDN для статического и публичного
контента.

Через CDN могут распространяться:

- изображения;
- статические ресурсы приложения;
- публичный медиа-контент;
- часть промоматериалов.

Персональные и чувствительные пользовательские данные не должны автоматически
публиковаться через публичный CDN.

## Alternatives

### Передавать всё через Application Services

Проще инфраструктурно, но хуже масштабируется для глобального публичного
контента.

## Consequences

### Positive

- снижение нагрузки на backend;
- уменьшение сетевой задержки;
- эффективное глобальное распространение статического контента.

### Negative

- требуется управление cache invalidation;
- необходимо контролировать, какие данные допускается кешировать.
