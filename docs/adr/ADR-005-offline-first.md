# ADR-005. Offline-first регистрация тренировок

**Статус:** Accepted

## Context

Пользователь может тренироваться:

- в лесу;
- в горах;
- за городом;
- в других местах с отсутствующим или нестабильным интернет-соединением.

Потеря связи не должна приводить к потере результатов тренировки.

## Decision

Мобильный клиент должен использовать offline-first подход для регистрации
тренировок.

Во время тренировки данные сохраняются локально.

После восстановления интернет-соединения выполняется синхронизация с backend.

Каждая тренировка должна иметь идентификатор, позволяющий безопасно повторить
отправку без создания дубликатов.

## Alternatives

### Требовать постоянное соединение

Отклонено, поскольку не соответствует реальным условиям тренировок.

### Передавать каждую точку только online

Отклонено, поскольку потеря соединения может привести к потере части тренировки.

## Consequences

### Positive

- тренировка работает без интернета;
- повышается надёжность;
- улучшается пользовательский опыт.

### Negative

- усложняется мобильный клиент;
- появляется синхронизация;
- необходимо разрешать конфликты;
- требуется idempotency backend API.
